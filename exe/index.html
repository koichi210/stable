exe ダウンロード

ふだん使っているツールの、Release フォルダ（GitHub）へのリンク集。Windows 用です。
フォルダに exe と、動かすのに必要な dll が入っています。dll があるツールは、exe と同じフォルダに置いて使ってください。

📂 Cheetos
画面キャプチャ / WPF / .NET Framework
画面（全画面・いまのモニター・いまのウィンドウ）を、決めた間隔で連続キャプチャして保存するツール。
📂 ColorConvert
色の確認・変換 / WPF / .NET Framework
R・G・B のスライダーと数値で色を作って、色の値を確認・変換できるツール。
📂 DuplicateFinder
重複ファイル削除 / WPF / .NET Framework 4.8
複数のフォルダから中身が同じファイルを探し出して、選んで削除できるツール。大きなファイルも先頭・末尾から順に比べて速く判定します。
📂 EventRecorder
マクロ記録・再生 / WPF / .NET Framework 4.8 / x64
キーボードとマウスの操作を記録して、そのまま再生できるツール。プレイリストで複数の記録をつなげて、ループ再生もできます。
📂 FFEdit
ファイル名の一括変換 / WPF / .NET Framework
フォルダ内のファイル・フォルダの名前を、通し番号などでまとめて変換するツール。タイムスタンプの更新もできます。
📂 FileArranger
ファイル整理 / WPF / .NET Framework
フォルダの移動や名前変更、ファイル名での並べ替え、ファイルの移動・振り分けをまとめて行う整理ツール。
📂 Launcher
ランチャー / WPF / .NET 10（ランタイムが必要）
よく使う exe や URL を登録しておいて、ワンクリックで起動できるランチャー。セクションごとに分けて、折りたたんで表示できます。※ .NET 10 デスクトップランタイムが必要です。
📂 Mailer
メール作成 / WPF / .NET Framework
宛先・件名・本文を決めておいて、ブラウザのメール作成画面をワンクリックで開くツール。日付入りの件名を、日をずらしてまとめて作ることもできます。
📂 Othello (C# / WPF)
ゲーム / WPF / .NET Framework
オセロ。人対人・人対COM・COM対COM の対戦ができて、一手戻す・一手進めるも使えます。
📂 DigitalClock
時計 / WPF / .NET Framework
時刻だけを大きく表示する、シンプルなデジタル時計。
📂 MotionCapture
画面録画 / WPF / .NET Framework
画面の指定した範囲を、FPS や画質を決めて動画（AVI）として録画するツール。
📂 OthelloMfc (C++ / MFC)
ゲーム / C++ / MFC
オセロ。C++（MFC）で作った版です。
📂 LoginHistory
稼働ログ / C++ / MFC
PC が動いていた時刻を、一定の間隔でログファイルに書き残していくツール。

※ Launcher だけは、.NET 10 デスクトップランタイムが入っている PC で動きます。入っていない場合は、起動時に案内が出ます。 ランタイムのダウンロード

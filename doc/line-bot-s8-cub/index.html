line-bot-s8-cub 図解ドキュメント

カブ隊用LINEボット「カブナビ8ちゃん」の仕組みと使い方を、Three.jsの立体図で1歩ずつ解説します。
PCのブラウザで開いて、画面共有や説明会で見せる用です。人名・ID・グループ名はすべてダミーです。

🌳 メニューの階層
Three.js / 全9ステップ
管理者 → 管理者用 → 保護者連絡 → アナウンス → 追加／削除… と、ボタンを押す順番を階層(ツリー)で表示。各ボタンでできることの表付き。
🗺️ 機能のつながり（しくみ図）
Three.js / 全8ステップ
グループ・アナウンス・案内文設定・活動予定・管理者が、どうつながっているかを図で。データの流れを矢印で追えます。
📋 ユースケース
Three.js / 全11ステップ
役割別の手順書。管理者が最初にやること、毎月の開催案内の出し方、保護者がやること。しくみ図の上で、使っている部分が光ります。チェックリスト付き。

「メニューの階層」は、Bot本体の scripts/rich-menu-config.js から自動生成した menus-data.js を読んで組み立てています。メニューを変えたら、Bot側のリポジトリで node scripts/build-tutorial-data.js を実行して menus-data.js を更新します。
3D図解の共通フレームワーク（lib/guide.js / lib/guide.css）は line-bot-mirai のドキュメントからのコピーです。

line-bot-s8-cub 使い方チュートリアル

カブ隊用LINEボット「カブナビ8ちゃん」の使い方を、リッチメニューの立体図で1歩ずつ解説します。
PCのブラウザで開いて、画面共有や説明会で見せる用です。人名・ID・グループ名はすべてダミーです。

🗺️ 機能のつながり（しくみ図）
Three.js / 全8ステップ
グループ・アナウンス・案内文設定・活動予定・管理者が、どうつながっているかを図で。データの流れを矢印で追えます。
🔧 管理者向け
Three.js / 全20ステップ
初回の準備（グループ登録・案内文設定）と、毎月の流れ（PDF取り込み → プレビュー → アナウンス予約）、管理者の追加・削除。
👪 保護者向け
Three.js / 全6ステップ
保護者に届くお知らせと、カブナビ8ちゃんにできること・できないこと。管理者になる手順も。

メニューの立体図は、Bot本体の scripts/rich-menu-config.js から自動生成した menus-data.js を読んで組み立てています。メニューを変えたら、Bot側のリポジトリで node scripts/build-tutorial-data.js を実行して menus-data.js を更新します。
3D図解の共通フレームワーク（lib/guide.js / lib/guide.css）は line-bot-mirai のドキュメントからのコピーです。

line-bot-s8-cub ドキュメント

カブ隊用LINEボット「カブナビ8ちゃん」の仕組みと使い方を、Three.jsの立体図で1歩ずつ解説します。
人名・ID・グループ名はすべてダミーです。

🌳 メニュー階層
Three.js / 全10ステップ
管理者 → 管理者用 → 保護者連絡 → アナウンス追加／削除… と、ボタンを押す順番を階層(ツリー)で表示。管理者のメニューと、一般(保護者)のメニューの両方。各ボタンでできることの表付き。
🗺️ アーキテクチャ
Three.js / 全8ステップ
グループ・アナウンス・案内文設定・活動予定・メンバ(管理者 / ユーザ)が、どうつながっているかを図で。データの流れを矢印で追えます。
🎬 ユースケース
Three.js / 自動再生 / 全10章
デモ動画のように、役割別の使い方が流れます。「▶ 自動で再生」で、最初の準備 → 毎月の開催案内 → 保護者が見る画面まで。字幕付き。「見る人」の切り替え(開催案内登録=管理者 / 開催案内受信=保護者)で、人が意識する場所だけを明るく表示できます。

「メニュー階層」は、Bot本体の scripts/rich-menu-config.js から自動生成した menus-data.js を読んで組み立てています。メニューを変えたら、Bot側のリポジトリで node scripts/build-tutorial-data.js を実行して menus-data.js を更新します。
3D図解の共通フレームワーク（lib/guide.js / lib/guide.css）は line-bot-mirai のドキュメントからのコピーです。

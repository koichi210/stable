DuplicateFinder ドキュメント

重複ファイル削除ツール「DuplicateFinder」(C# / WPF)の使い方と仕組みを、Three.jsの立体図で1歩ずつ解説します。
フォルダ以下で中身がバイナリまで同じファイルを見つけて、残す1件を決めて消すツールです。画面のスクリーンショットは、このガイド用に作ったダミーフォルダだけを使っています。

🖱️ 使い方
Three.js / 実画面のスクリーンショット / 全9ステップ
フォルダを入れる → 条件を決める → 検索 → 結果の見かた → 自動選択 → 確認して削除。実際の画面を3D空間に並べ、ステップごとにカメラが注目点へ寄ります。
🌊 データの流れ
Three.js / ブロックの絞り込みアニメ / 全9ステップ
ファイル一覧 → サイズで仲間分け → 先頭と末尾 → 全員同時のチャンク比較 → 重複グループ → 一覧 → 削除。違うと分かった瞬間に読むのをやめるので、大きな動画でも速い理由が見えます。
🧱 内部設計
Three.js / クラス構成の3D図 / 全9ステップ
画面・画面用モデル・ロジック・外部の4層と、MainWindow / DuplicateScanner / RowMarker などの実際のクラス・ファイルの役割と依存関係。

ソースは Essentials/DuplicateFinder(共通部品は Essentials/_Common)。 3D図解の共通フレームワークは ../lib/guide.js / ../lib/guide.css です。 ドラッグで回転、ホイールで拡大、矢印キー(←→)でステップ送りができます。

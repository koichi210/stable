LoginHistory ドキュメント

PCが動いていた時刻を、ログファイルに1行ずつ書き残す稼働ログツール「LoginHistory」(C++ / MFC)の使い方と仕組みを、Three.jsの立体図で1歩ずつ解説します。
「ロギング実行」を押すたびに今の日時を1行追記し、前回から設定した間隔どおりでなければ行末に ! を付けます。ログの出力先はこのガイド用のダミー、日時の例もダミーです。

🖱️ 使い方
Three.js / 実画面のスクリーンショット / 全8ステップ
出力先を決める → ロギング実行 → set.ini で間隔を変える → ログの読みかた(! の意味)。実際の画面を3D空間に並べ、ステップごとにカメラが注目点へ寄ります。
🌊 データの流れ
Three.js / ブロックが流れるアニメ / 全8ステップ
ボタン → set.ini の間隔 → 現在時刻 → ログを開く → 前回の時刻と比べる → 1行追記。間隔どおりか、ずれているかで行末の印が変わる様子が見えます。
🧱 内部設計
Three.js / クラス構成の3D図 / 全8ステップ
アプリ・ダイアログ・補助関数・OS/CRT の層と、LoginHistoryApp / LoginHistoryDlg / ReadLastTime / IsOnSchedule などの実際のクラス・関数の役割と依存関係。

ソースは Essentials/LoginHistory/Source(実行ファイルは Essentials/LoginHistory/Release)。 3D図解の共通フレームワークは ../lib/guide.js / ../lib/guide.css です。 ドラッグで回転、ホイールで拡大、矢印キー(←→)でステップ送りができます。

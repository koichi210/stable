Essentials 設計図

よく使うツールの「使い方」「データの流れ」「内部設計」を、動く3D図で解説します。
使い方は実際のアプリ画面のスクリーンショットを使っています（表示しているパス・名前はすべてダミーです）。

🎬 EventRecorder
マクロ記録・再生 / WPF / .NET Framework 4.8
キーボード・マウス操作を記録して再生するツール。入力フックから保存・再生までの流れと、5層の内部構造を解説。
🗑️ DuplicateFinder
重複ファイル削除 / WPF / .NET Framework 4.8
サイズ → 先頭末尾 → チャンク比較と絞り込んでいく多段判定を、ファイルブロックのアニメで解説。
🚀 Launcher
ランチャー / WPF / .NET 10
設定の読み込みからボタン表示、クリックで起動、自動保存までの流れと、層構造を解説。
📂 FileArranger
ファイル整理 / WPF / .NET Framework
フォルダ・ファイルの移動、リネーム、並べ替え、振り分けの仕組みと、履歴・復元の流れを解説。
📸 Cheetos
画面キャプチャ / WPF / .NET Framework
画面（全画面・モニター・ウィンドウ）を決めた間隔で連続キャプチャして保存するツール。撮影と保存の流れを解説。
✏️ FFEdit
ファイル名の一括変換 / WPF / .NET Framework
通し番号などで名前をまとめて変換し、元に戻せる仕組みとタイムスタンプ更新を解説。
✉️ Mailer
メール作成 / WPF / .NET Framework
宛先・件名・本文を決めて、ブラウザのメール作成画面を開くツール。日付入り件名の置換と一括作成を解説。
🕒 DigitalClock
時計 / WPF / .NET Framework
時刻だけを表示するシンプルな時計。半透明化と位置の保存・復元の仕組みを解説。
⚫ Othello
ゲーム / WPF / .NET Framework
オセロ（C#版）。石を挟んで裏返す判定、COMの思考、一手戻す仕組みを3D盤面で解説。
⚪ OthelloMfc
ゲーム / C++ / MFC
オセロ（C++/MFC版）。MFCのクラス構成と対局の流れを解説。
📝 LoginHistory
稼働ログ / C++ / MFC
PCが動いていた時刻をログファイルに書き残すツール。追記と間隔判定の流れを解説。

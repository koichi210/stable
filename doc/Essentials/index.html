Essentials 設計図

よく使うツールの「使い方」「データの流れ」「内部設計」を、動く3D図で解説します。
使い方は実際のアプリ画面のスクリーンショットを使っています（表示しているパス・名前はすべてダミーです）。

🎬 EventRecorder
マクロ記録・再生 / WPF / .NET Framework 4.8
キーボード・マウス操作を記録して再生するツール。入力フックから保存・再生までの流れと、5層の内部構造を解説。
🗑️ DuplicateFinder
重複ファイル削除 / WPF / .NET Framework 4.8
サイズ → 先頭末尾 → チャンク比較と絞り込んでいく多段判定を、ファイルブロックのアニメで解説。
🚀 Launcher
ランチャー / WPF / .NET 10
設定の読み込みからボタン表示、クリックで起動、自動保存までの流れと、層構造を解説。
📂 FileArranger
ファイル整理 / WPF / .NET Framework
フォルダ・ファイルの移動、リネーム、並べ替え、振り分けの仕組みと、履歴・復元の流れを解説。

EventRecorder ドキュメント

マウス・キーボード操作を「記録」して「再生」する Windows 用ツール(C# / WPF / .NET Framework 4.8)の、使い方と仕組みを Three.js の立体図でステップ送りに解説します。
3Dはドラッグで回転、ホイールで拡大縮小できます。画面写真の中身(ファイル名・メモ・座標)はすべてダミーです。

🎬 使い方
Three.js / 実画面の写真 / 全9ステップ
実際の画面を3D空間に並べて、記録 → 編集 → 保存 → 再生 → プレイリストの順に、カメラが寄りながら手順を説明します。ホットキーや最小化などの便利機能も。
🌊 データの流れ
Three.js / 粒子アニメ / 全10ステップ
入力フック → イベント → 行データ → JSONファイル → 再生 → 入力の再送信、までを光の粒の流れで追います。保存先の決まり方や、停止・ロック時の安全装置も。
🏗️ 内部設計
Three.js / 層構造の3D図 / 全8ステップ
UI層・ルール層・データ層・共通部品(_Common)・OS の5層に、実際のクラス名・ファイル名を並べて、責務と依存の向きを説明します。

ソースは Essentials/EventRecorder(共通部品は Essentials/_Common)。 3D図解の共通フレームワークは ../lib/guide.js / ../lib/guide.css です。

Launcher ドキュメント

exe・URL・フォルダなどをボタンとして登録しておき、ワンクリックで起動できるランチャー(.NET 10 / WPF)の仕組みと使い方を、Three.jsの立体図で1歩ずつ解説します。
図の中の画面は、図解用に作ったダミー設定(メモ帳・電卓・サンプルサイト)で撮影したものです。

🖱️ 使い方
Three.js / 実画面のスクリーンショット / 全8ステップ
起動画面 → ボタンで起動 → セクション開閉 → 項目・セクションの追加 → 編集・削除 → ツールバー → 自動保存。実際の画面を3D空間に並べて、ステップごとにカメラが寄ります。
🔀 データの流れ
Three.js / 粒と矢印のアニメーション / 全8ステップ
保存先の決定 → 設定JSONの読み込み → 画面表示 → クリックして起動 → 編集して自動保存 → 読み込み失敗時の保護 → 保存先の変更、を光る粒で追えます。
🧱 内部設計
Three.js / レイヤの立体図 / 全7ステップ
画面・モデル・サービス・共有部品(_Common)・外部の5段構成。MainWindow / ConfigService / LaunchService などの実クラス名と、依存の向きを3Dで。

ソースは Essentials/Launcher(共有部品は Essentials/_Common)にあります。 3D図解の共通フレームワーク(../lib/guide.js / ../lib/guide.css)は Essentialsの図解ページで共有しています。

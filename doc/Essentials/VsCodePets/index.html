VsCodePets ドキュメント

VS Code のパネルにペットを住まわせる拡張機能「vscode-pets」の改造版(Flying。TypeScript / VS Code 拡張)の、使い方と仕組みを Three.js の立体図でステップ送りに解説します。
3Dはドラッグで回転、ホイールで拡大縮小できます。VS Code の実画面は撮れないため、パネルの絵は「再現図」(リポジトリ内のオリジナル画像を並べて作ったもの)です。

🎬 使い方
Three.js / 画像つき / 全9ステップ
VSIX のビルドとインストール → ペットの追加(種類・色・名前)→ 秘書さん5人 → 掴む・卵・おしゃべりなどの操作 → コマンドと設定、の順に説明します。
🌊 データの流れ
Three.js / 粒子アニメ / 全11ステップ
拡張の起動 → webview の HTML 生成 → 100ms ごとの tick → ペットの状態遷移 → GIF の切り替えと位置の更新、までを光の粒の流れで追います。メッセージと状態の保存も。
🏗️ 内部設計
Three.js / 層構造の3D図 / 全10ステップ
拡張側・共通・webview側・ペットクラス・画像アセットの5層に、実際のファイル名・クラス名を並べて説明します。今回の改造点(Flying・秘書さん追加)も。

ソースは Essentials/VsCodePets(上流 tonybaloney/vscode-pets の MIT コードがベース。ペットの画像はすべてこのリポジトリで描いたオリジナル)。 3D図解の共通フレームワークは ../lib/guide.js / ../lib/guide.css です。

ClaudeOffice ドキュメント

Claude Code の会話を3Dの箱庭オフィスで見守るローカル専用ダッシュボード(Node.js + Three.js)の、使い方と仕組みを Three.js の立体図でステップ送りに解説します。
3Dはドラッグで回転、ホイールで拡大縮小できます。画面写真の中身(プロジェクト名・会話)はすべてダミーです。

🎬 使い方
Three.js / 実画面の写真 / 全9ステップ
実際の画面を3D空間に並べて、スキン3種・動作モード・席を立って歩き回る動き・詳細の窓と続きを送る欄・時間プレビュー・通知の順に、カメラが寄りながら説明します。
🌊 データの流れ
Three.js / 粒子アニメ / 全10ステップ
Claude Code の会話記録・在席ファイル → server.js → /api/state → 画面のポーリング、と「続きを送る」(パイプ / claude --resume)・Stop フック通知の経路を光の粒で追います。
🏗️ 内部設計
Three.js / 層構造の3D図 / 全9ステップ
app.js(buildSkin / ctx / frame)・world / makai / fancy・avatar・wander(通路グラフと状態機械)・spots・超軽量(applyUltra)の関係を、実際のファイル名・関数名で説明します。

ソースは Essentials/ClaudeOffice(server.js と public/)。 3D図解の共通フレームワークは ../lib/guide.js / ../lib/guide.css です。

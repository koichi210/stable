FileArranger ドキュメント

フォルダ・ファイルの移動・名前変更・並べ替え・振り分けをまとめて行う、Windows デスクトップツール(C# / WPF)の「動きのある設計図」です。
Three.js の立体図を1歩ずつ進めながら、使い方・データの流れ・内部設計を見られます。画面のフォルダ名・ファイル名はすべて撮影用のダミーです。

🖥️ 使い方
Three.js + 実画面のスクリーンショット / 全8ステップ
実際のウィンドウを3D空間に並べ、Common・MoveDir・RenameDir・SortFileName・MoveFile・PartitionFile の6タブへカメラが寄ります。手前ではフォルダ/ファイルの塊が動いて、操作の結果を見せます。
🌊 データの流れ
Three.js / 全9ステップ
入力フォルダ → 一覧 → 新しい名前の決定 → 移動・リネーム(重複回避) → 結果。別スレッド実行、元に戻す履歴、設定のJSON保存/読込まで、ファイルの塊が動くアニメで追います。
🧱 内部設計
Three.js / 階段状の5層 / 全7ステップ
入口・画面(MainWindow の partial 分割)・アプリ固有ロジック(Logic/Utils/FileSorter…)・共通部品 _Common・外部ライブラリ。実際のクラス名・ファイル名と、依存の向き、1回の操作が層を降りる様子。

ソースは Essentials/FileArranger(共通部品は Essentials/_Common)。 3D図解の共通フレームワークは ../lib/guide.js / ../lib/guide.css、 このツール用の部品は fa-lib.js、スクリーンショットは img/(3Dのテクスチャ用に fa-img.js へも同じ画像をデータとして持っています)。 HTMLをダブルクリック(file://)で開いても動きます。

FFEdit ドキュメント

フォルダ内のファイル・フォルダ名を通し番号などで一括変換し、タイムスタンプの更新や移動・コピーもできるツール「FFEdit」(C# / WPF / .NET Framework)の使い方と仕組みを、Three.jsの立体図で1歩ずつ解説します。
変換は直前の操作1回分を元に戻せるので、安心して試せます。画面のスクリーンショットは、このガイド用に作ったダミーフォルダだけを使っています。

🖱️ 使い方
Three.js / 実画面のスクリーンショット / 全10ステップ
対象フォルダを入れてリストアップ → 通し番号などで名前を一括変換 → 実行 → 復元。タイムスタンプの更新と、移動・コピー・空フォルダ削除の使い方まで。実際の画面を3D空間に並べ、ステップごとにカメラが寄ります。
🌊 データの流れ
Three.js / ブロックが流れるアニメ / 全11ステップ
フォルダ → 自然順の一覧 → 処理対象 → 新しい名前の計算 → 実際の移動と「復元用の記録」 → 一覧の更新。タイムスタンプ・移動/コピー・設定の保存先の流れも。
🧱 内部設計
Three.js / クラス構成の3D図 / 全9ステップ
画面・処理ロジック・共通部品(_Common)・OS/外部の層と、MainWindow / Rename / TimeStamp / Function / FileMng などの実際のクラス・ファイルの役割と依存関係。

ソースは Essentials/FFEdit(共通部品は Essentials/_Common)。 3D図解の共通フレームワークは ../lib/guide.js / ../lib/guide.css です。 ドラッグで回転、ホイールで拡大、矢印キー(←→)でステップ送りができます。

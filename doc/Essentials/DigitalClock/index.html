DigitalClock ドキュメント

時刻だけを表示する、小さなデジタル時計「DigitalClock」(C# / WPF / .NET Framework)の使い方と仕組みを、Three.jsの立体図で1歩ずつ解説します。
最前面・半透明の小さなウィンドウに HH:mm:ss を出すだけのツールで、ドラッグで好きな場所へ動かせます。画面のスクリーンショットは、このガイド用に撮った時計の窓と見本テキストだけです。

🖱️ 使い方
Three.js / 実画面のスクリーンショット / 全7ステップ
起動 → 時刻が進む → ドラッグで移動 → 半透明で他のウィンドウに重ねる → 位置を覚える。実際の画面を3D空間に並べ、ステップごとにカメラが注目点へ寄ります。
🌊 データの流れ
Three.js / 粒が流れるアニメ / 全7ステップ
500msごとのタイマー → 時刻の整形 → 画面。起動時の位置の復元(画面外なら捨てる)、半透明化のWin32の仕掛け、ドラッグ移動、終了時の保存まで。
🧱 内部設計
Three.js / クラス構成の3D図 / 全6ステップ
MainWindow / Logic / WindowPlacement と、共通部品 JsonFileStorage / AtomicFile、user32.dll の関係。実際のクラス・ファイル・関数名で解説します。

ソースは Essentials/DigitalClock(共通部品は Essentials/_Common)。 3D図解の共通フレームワークは ../lib/guide.js / ../lib/guide.css です。 ドラッグで回転、ホイールで拡大、矢印キー(←→)でステップ送りができます。

Othello ドキュメント

オセロ(人対人・人対COM・COM対COM、一手戻す/進める)を遊べる Windows 用ツール(C# / WPF / .NET Framework)の、使い方と仕組みを Three.js の立体図でステップ送りに解説します。
3Dはドラッグで回転、ホイールで拡大縮小できます。画面写真は対局の盤面だけで、個人情報は含みません。

🎬 使い方
Three.js / 実画面の写真 / 全9ステップ
実際の画面を3D空間に並べて、石の置き方・8方向の挟み・COM対戦・一手戻す/進める・持ち時間・棋譜の順に、カメラが寄りながら説明します。石が裏返る3Dの実演つき。
🌊 データの流れ
Three.js / 3Dの盤 / 粒子アニメ / 全11ステップ
クリック → マス → 8方向の反転判定 → 手番交代/パス/終局 → 履歴 → 再描画を、3Dの盤で石が裏返る様子と光の粒で追います。COMの評価、一手戻す(履歴の再生)、棋譜も。
🏗️ 内部設計
Three.js / 層構造の3D図 / 全10ステップ
UI層・描画層・ルール層・共通部品・OS の5層に、実際のクラス名・ファイル名を並べて、責務と依存の向き(GameMaster は誰も呼ばない)を説明します。

ソースは Essentials/Othello(共通部品は Essentials/_Common)。 3D図解の共通フレームワークは ../lib/guide.js / ../lib/guide.css、盤の3D部品は board3d.js です。

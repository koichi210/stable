SecretaryGadget(秘書さんガジェット) ドキュメント

Outlook の新着メール・会議の開始前・Teams のメンションを、画面右下からせり上がってくる「秘書さん」の吹き出しで知らせる Windows 用の常駐ガジェット(C# / WPF / .NET 9)の、使い方と仕組みを Three.js の立体図でステップ送りに解説します。
3Dはドラッグで回転、ホイールで拡大縮小できます。画面写真の中身(呼び名・差出人・件名・会議名・時刻)はすべてダミーです。

🎬 使い方
Three.js / 実画面の写真 / 全9ステップ
起動 → 秘書さんを呼ぶ → トレイメニュー → スキン変更 → タイマー(ホイールで時間を回して設定 / 時間になったら通知)の順に、実際の画面を3D空間に並べて説明します。
🌊 データの流れ
Three.js / 粒子アニメ / 全11ステップ
Outlook / Teams の見張り役 → お知らせキュー → 吹き出し表示までと、タイマー(入力 → TimerKeeper → timers.json → 期限の確認 → 通知)の流れを光の粒で追います。
🏗️ 内部設計
Three.js / 層構造の3D図 / 全8ステップ
UI層・お知らせ層・見張り役・保存層・OS の層に、実際のクラス名・ファイル名(App.Tray / App.Timer / Notice / SecretaryWindow / TimerDialog / TimerKeeper / WheelColumn ほか)を並べて、責務と依存の向きを説明します。

ソースは Essentials/SecretaryGadget。このPC専用で、Release\SecretaryGadget.exe から直接起動する作りです。 3D図解の共通フレームワークは ../lib/guide.js / ../lib/guide.css です。

Cheetos ドキュメント

画面(全画面・モニター・ウィンドウ)を決めた間隔で連続キャプチャして保存し、撮った画像を切り取り・回転・縦横の振り分け・結合・集約で仕上げる Windows 用ツール(C# / WPF / .NET Framework 4.0 Client・x64)の、使い方と仕組みを Three.js の立体図でステップ送りに解説します。
3Dはドラッグで回転、ホイールで拡大縮小、矢印キー(←→)でステップ送りができます。画面写真はアプリの設定画面だけで、撮影した画像(自分の画面)は一切載せていません。写っているパス・ファイル名・画像はすべてダミーです。

🎞️ 使い方
Three.js / 実画面の写真 / 全14ステップ
CaptureWindow タブで「保存先・撮る対象・待ち時間・繰り返し数」を決めて連続キャプチャ。そのあと PictTrim / Rotation / DistOrient / PictMerge / FileCollect の各タブで画像を仕上げる流れを、実際の画面を3D空間に並べてカメラが寄りながら説明します。
🌊 データの流れ
Three.js / 粒子・ブロックのアニメ / 全13ステップ
設定 → UIスレッドで値を読み取り → 専用の撮影スレッド → (マウス移動・待機・撮影) × 行 × 繰り返し → PNGファイル。そのあと「バックアップ → 加工 → 上書き」の共通パターンで各タブが画像を処理していく様子を、光の粒の流れで追います。
🏗️ 内部設計
Three.js / 層構造の3D図 / 全11ステップ
画面・加工ロジック・共通部品(_Common)・OS/外部・テストの層に、MainWindow(partial 6ファイル) / CaptWindow / PicEdit / PictMerge / Rotation / Logic などの実際のクラス・ファイルを並べて、責務と依存の向きを説明します。

ソースは Essentials/Cheetos(共通部品は Essentials/_Common)。 3D図解の共通フレームワークは ../lib/guide.js / ../lib/guide.css です。

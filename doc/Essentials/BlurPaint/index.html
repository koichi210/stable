BlurPaint ドキュメント

スクリーンショットに矢印・枠・文字・番号・蛍光ペン・ぼかし／モザイクの注釈を入れる、ブラウザだけで動く軽量ペイントエディタ(HTML / CSS / JavaScript・依存なし)の、使い方と仕組みを Three.js の立体図でステップ送りに解説します。
3Dはドラッグで回転、ホイールで拡大縮小できます。画面写真の中身(画像・文字・番号)はすべて自作のダミーです。

🎬 使い方
Three.js / 実画面の写真 / 全9ステップ
実際の画面を3D空間に並べて、画像を入れる → 注釈を描く → ぼかす → 選択・変形 → トリミング → コピー/保存の順に、カメラが寄りながら手順を説明します。ショートカット一覧も。
🌊 データの流れ
Three.js / 粒子アニメ / 全10ステップ
貼り付け・ドロップ → ベース画像 → 注釈オブジェクト → 履歴 → 合成描画 → PNG/JPEG/WebP の書き出し、までを光の粒の流れで追います。ぼかしの計算やトリミングの仕組みも。
🏗️ 内部設計
Three.js / 層構造の3D図 / 全8ステップ
画面・入力操作・状態と履歴・描画・ブラウザ API の5層に、実際の関数名・状態名を並べて、1本の app.js の責務と依存の向きを説明します。

ソースは Essentials/BlurPaint(index.html / style.css / app.js)。 3D図解の共通フレームワークは ../lib/guide.js / ../lib/guide.css です。

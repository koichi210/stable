Mailer ドキュメント

宛先・件名・本文をあらかじめ決めておき、ボタン1つでブラウザ(Gmail)のメール作成画面を開くツール(C# / WPF / .NET Framework)の仕組みと使い方を、Three.jsの立体図で1歩ずつ解説します。件名に日付を入れて、日をずらした作成画面をまとめて開く機能もあります。
図の中の画面は、図解用に作ったダミー設定(example.com の架空アドレス・架空の件名)で撮影したものです。

🖱️ 使い方
Three.js / 実画面のスクリーンショット / 全8ステップ
ブラウザパス → 宛先 → 件名の置換記号 → 本文 → ブラウザで表示 → 一括表示 → 設定の保存。実際の画面を3D空間に並べて、ステップごとにカメラが寄ります。
🔀 データの流れ
Three.js / 粒と矢印のアニメーション / 全9ステップ
保存先の決定と設定の読み込み → 入力値の取得 → 件名の日付置換 → URLエスケープ → 長さチェックとブラウザ起動 → 一括表示のくり返し → 保存、を光る粒で追えます。
🧱 内部設計
Three.js / レイヤの立体図 / 全7ステップ
画面(MainWindow)・ロジック(Logic.cs)・共有部品(_Common)・外部の構成。MainWindow / Logic / WpfSaveRestore などの実クラス名と、依存の向きを3Dで。

ソースは Essentials/Mailer(共有部品は Essentials/_Common)にあります。 3D図解の共通フレームワーク(../lib/guide.js / ../lib/guide.css)は Essentialsの図解ページで共有しています。

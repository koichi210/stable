HeifToPng ドキュメント

iPhone などで撮った HEIF 画像(.heic / .heif / .hif)を、フォルダごとまとめて PNG に変換するツール「HeifToPng」(C# / WPF)の使い方と仕組みを、Three.js の立体図で1歩ずつ解説します。
画面のスクリーンショットは、このガイド用に作ったダミーの写真フォルダ(グラデーションの絵だけ)を使っています。

🖱️ 使い方
Three.js / 実画面のスクリーンショット / 全7ステップ
変換元を入れる → オプション → 変換開始・中止 → ログで結果を見る → できあがる PNG(向き・色・撮影情報)。実際の画面を3D空間に並べ、カメラが注目点へ寄ります。
🌊 データの流れ
Three.js / ブロックが流れるアニメ / 全9ステップ
HEIF を集める → 作業員(並列)に配る → libheif で復号 → 撮影情報(GPS など)を消す → PNG に書く → 集計。WIC から Magick.NET に替えた理由の速さ比べも。
🧱 内部設計
Three.js / 層構造の3D図 / 全8ステップ
画面・設定・変換・共通部品・外部の5層と、MainWindow / HeifConverter / AppSettings などの役割、スレッドのつなぎ方、失敗の扱い、テスト。

ソースは Essentials/HeifToPng(共通部品は Essentials/_Common)。 3D図解の共通フレームワークは ../lib/guide.js / ../lib/guide.css です。 ドラッグで回転、ホイールで拡大、矢印キー(←→)でステップ送りができます。

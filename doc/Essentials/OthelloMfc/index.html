OthelloMfc ドキュメント

オセロ(C++ / MFC版)「OthelloMfc」の使い方と仕組みを、Three.jsの立体図で1歩ずつ解説します。
人 vs COM・COM vs COM などで遊べる、ダイアログベースのオセロです。盤面のスクリーンショットは、このガイド用に実際に遊んだ画面です(個人情報は写っていません)。

🖱️ 使い方
Three.js / 実画面のスクリーンショット / 全9ステップ
メニューの見かた → 置ける場所の点 → クリックで打つ → 手番・スコア・持ち時間 → 棋譜と一手戻す → 終局。実際の画面を3D空間に並べ、ステップごとにカメラが注目点へ寄ります。
🌊 データの流れ
Three.js / 石の裏返しとCOM思考のアニメ / 全8ステップ
クリック → 着手判定(8方向) → 石を置いて裏返す → 手番交代・パス・終局 → COMの思考(候補手の評価と優先度) → 棋譜と一手戻す/送る。盤の上で石が実際に動きます。
🧱 内部設計
Three.js / クラス構成の3D図 / 全8ステップ
画面・進行・ルール・外部の層と、OthelloApp / OthelloDlg / GameManager / Board / ComPlayer の責務と依存関係。MFCのメッセージマップ、タイマ、描画も。

ソースは Essentials/OthelloMfc/Source(実行ファイルは Essentials/OthelloMfc/Release)。 3D図解の共通フレームワークは ../lib/guide.js / ../lib/guide.css です。 ドラッグで回転、ホイールで拡大、矢印キー(←→)でステップ送りができます。
